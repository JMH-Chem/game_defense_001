# 등불 수호자 (Lantern Keeper) — 게임 기획서

> 어둠이 밀려오는 밤, 마지막 등불을 지켜라.

| 항목 | 내용 |
|---|---|
| 장르 | 판타지 타워 디펜스 (경로형) + 로그라이트 성장 |
| 플랫폼 | 웹 브라우저 (데스크톱·태블릿·모바일, 설치 불필요) |
| 플레이 타임 | 스테이지당 10~18분, 무한 모드 별도 |
| 타깃 | 킹덤 러시·블룬스 TD를 즐긴 캐주얼~미드코어 전략 게이머 |
| 기술 | HTML5 Canvas 2D + 바닐라 JS, 외부 에셋 0개 (그래픽·사운드 전부 코드 생성) |

---

## 1. 콘셉트

세상의 빛이 모두 꺼진 밤. 마지막 남은 **등불**이 꺼지면 어둠이 세상을 삼킵니다. 플레이어는 등불지기가 되어 길을 따라 몰려오는 어둠의 군세를 타워·영웅·주문으로 막아냅니다.

**한 줄 요약:** *킹덤 러시의 손맛 + 블룬스의 분기 업그레이드 + TFT의 시너지 + 로그라이크의 룬 선택.*

### 1-1. 핵심 재미 (디자인 기둥)

1. **배치의 퍼즐** — 길목·교차로·하늘길을 읽고 어디에 무엇을 지을지 결정하는 공간 퍼즐.
2. **빌드의 개성** — 같은 스테이지라도 공명(시너지)과 룬 조합에 따라 매번 다른 전략이 나온다.
3. **손에 잡히는 개입** — 영웅 이동, 주문, 조기 호출로 관전이 아니라 *지휘*하는 감각.
4. **밤의 분위기** — 어두운 맵 위에서 타워와 등불만 빛나는 시각적 정체성.

### 1-2. 참고한 게임과 차용 요소

| 원작 | 차용한 요소 | 등불 수호자에서의 변형 |
|---|---|---|
| Kingdom Rush | 고정 경로, 병영의 저지(blocking), 조작 가능한 영웅, 주문, 조기 호출 보너스 | 병영 집결지 지정, 영웅 3종 선택, 증원군은 길 위로 자동 스냅 |
| Bloons TD | 업그레이드 분기, 타워별 조준 우선순위 | Lv.3에서 두 갈래 중 하나로 **최종 진화** (총 12종) |
| Teamfight Tactics | 같은 종류를 모으면 발동하는 시너지 | **공명** — 타워 종류별 2/4/6 단계 + 6종 모두 보유 시 '조화' |
| Slay the Spire / 뱀파이어 서바이버 | 진행 중 3장 중 1장 선택 | **룬** 25종, 3웨이브마다 선택, 1회 다시 뽑기 |
| Plants vs. Zombies | 적 등장 전 웨이브 구성 미리보기, 새 적 소개 카드 | 다음 웨이브 아이콘 미리보기 + 첫 등장 시 특성 카드 |
| Element TD | 장갑/마법 저항 상성 | 물리·마법·고정 피해 3종과 적의 방어력·마법 저항 |

## 2. 게임 루프

```
[원정지·영웅·난이도 선택]
        ↓
[준비 단계] 시작 골드로 타워 건설 → [전투 시작]
        ↓
┌─▶ [웨이브 진군] 타워 자동 공격 · 영웅 이동 · 주문 사용
│        ↓  (적 처치 → 골드 · 영웅 경험치)
│   [웨이브 사이 18초] 건설·업그레이드 · 조기 호출(보너스 골드)
│        ↓  (3웨이브마다)
│   [룬 선택] 3장 중 1장
└────────┘
        ↓ 최종 웨이브 + 보스 격파
[결과] 남은 생명으로 별 1~3개 → 다음 원정지 · 무한 모드 해금
```

- **승리:** 마지막 웨이브의 모든 적 처치.
- **패배:** 생명 0 (어둠의 군주는 등불에 닿는 즉시 패배).
- **별:** 생명 90% 이상 ★★★, 50% 이상 ★★, 그 외 ★.

## 3. 시스템 상세

모든 수치의 원본은 [`js/data.js`](../js/data.js) 입니다. 거리 단위는 타일(48px), 시간 단위는 초.

### 3-1. 타워 (6종 × 3레벨 + 최종 진화 2갈래)

| 타워 | 비용 | 역할 | 공중 | 최종 진화 A | 최종 진화 B |
|---|---|---|---|---|---|
| 궁수탑 | 70 | 빠른 단일 물리 | O | **매의 둥지** — 초장거리, 방어 60% 관통, 25% 치명타(×2.5) | **연발 쇠뇌** — 최대 3명 동시 사격 |
| 대포탑 | 110 | 범위 물리 | X | **대형 박격포** — 초장거리 예측 포격, 불타는 지면 | **화염 방사기** — 근거리 부채꼴 마법 피해 + 화상 |
| 서리탑 | 90 | 둔화 | O | **빙결 첨탑** — 30% 빙결, 언 적은 피해 +50% | **눈보라 제단** — 범위 내 모두에게 지속 피해·강한 둔화 |
| 비전탑 | 120 | 연쇄 마법 | O | **폭풍 코일** — 8회 연쇄 + 기절 | **공허 프리즘** — 지속 광선, 같은 대상에 최대 ×5 가속 (보스 킬러) |
| 성소 | 100 | 버프·경제 | — | **황금 성소** — 웨이브당 +60G, 범위 내 처치 +3G | **전쟁 성소** — 피해 +40%, 공속 +20%, 사거리 +0.5 |
| 병영 | 90 | 저지 | X | **성기사단** — 고방어·재생 탱커 | **광전사 막사** — 고공격·흡혈 |

**설계 의도**
- 기본 타워는 싸지만 약하고, 업그레이드일수록 **골드 대비 효율이 높아진다** — 무작정 1레벨 타워를 깔면 지도록 밸런싱 (시뮬레이터로 검증, §6).
- 최종 진화의 두 갈래는 항상 *단일 vs 다수* 혹은 *사거리 vs 근접*처럼 **역할이 반대**가 되도록 설계해 선택이 의미 있게 했다.
- 성소는 공격력이 없는 대신 경제와 버프를 담당해 "지금 투자할까, 방어할까"의 긴장을 만든다. 여러 성소의 버프는 겹치지 않고 가장 강한 것 하나만 적용.
- 조준 우선순위 4종: 선두 / 후미 / 강적 / 근접 (`T` 키로 순환).

### 3-2. 공명 (시너지)

같은 종류의 타워 수에 따라 단계별 보너스. 타워 패널 좌상단에 실시간 표시.

| 공명 | 단계 | 효과 |
|---|---|---|
| 명사수 (궁수) | 2/4/6 | 궁수탑 공속 +10% / +25% / +45% |
| 포격 (대포) | 2/4/6 | 폭발 범위 +10% / +20% / +35% · 3단계: 피격 적 방어력 -25% |
| 혹한 (서리) | 2/4/6 | 둔화 +5 / +10 / +15%p · 3단계: 둔화된 적이 받는 피해 +15% |
| 뇌운 (비전) | 2/4/6 | 연쇄 +1 / +2 / +3 · 3단계: 프리즘 가속 +50% |
| 신앙 (성소) | 2/3/4 | 성소 효과 +25% / +50% / +100% |
| 군단 (병영) | 2/4/6 | 병사 체력 +20% / +40% / +70% · 3단계: 병사 +1 |
| **조화** | 6종 모두 | 모든 타워 피해 +12% |

→ "한 종류에 몰빵(공명 3단계)" vs "골고루(조화)" 라는 두 축의 빌드 방향이 생긴다.

### 3-3. 적 (일반 8종 + 분열체 + 보스 3종)

| 적 | 특징 | 대응 |
|---|---|---|
| 그림자 도깨비 | 기본 졸개 | 무엇이든 |
| 잿빛 늑대 | 매우 빠름 | 둔화, 병영 |
| 황혼 박쥐 | **비행** — 길을 무시하고 점선 하늘길로 등불까지 직선 비행 | 궁수·서리·비전, 하늘길 근처 배치 |
| 철갑 골렘 | 방어력 55% | 마법, 매의 둥지(관통), 화염 |
| 타락한 주술사 | 3초마다 주변 적 10% 회복, 마저 50% | 우선 처치(강적 조준), 물리 |
| 분열 점액 | 죽으면 작은 점액 2마리 | 범위 공격 |
| 울부짖는 망령 | **저지 불가**, 마저 75% | 물리 타워 |
| 공허 방패병 | 체력만큼의 보호막 + 방어 30% | 지속 피해, 프리즘 |
| 👑 오우거 족장 | 막아선 병사를 짓밟아 기절 | 원거리 집중, 유성 |
| 👑 그림자 비룡 | 비행 보스, 체력 20%마다 박쥐 떼 소환 | 대공 화력, 범위 |
| 👑 어둠의 군주 | 졸개 소환, 체력 50%에서 거대 보호막, 닿으면 즉시 패배 | 프리즘 + 버프, 빙결로 시간 벌기 |

보스는 기절 지속 30%, 둔화 효과 60%만 받는다(경직 남용 방지).

### 3-4. 영웅 (3종)

| 영웅 | 역할 | 기본기 | 기술 (`E`) |
|---|---|---|---|
| 아렌 — 강철의 기사 | 근접 탱커, 넓은 저지 범위 | 방어 45%, 체력 재생 | 방패 강타: 주변 피해 + 1.6초 기절 |
| 리라 — 숲의 명궁 | 원거리 물리, 대공 | 사거리 3.6 | 화살비: 지정 지역 8회 범위 피해 |
| 세린 — 별의 마법사 | 원거리 마법 범위 | 폭발 구체 | 시간 균열: 4초간 70% 둔화 + 마법 피해 |

- 모든 영웅은 지상 적을 **막아선다** (근접 시 저지). 클릭 → 지도 클릭으로 이동.
- 처치 경험치로 최대 Lv.10 (레벨당 체력·피해 +10%). 사망 시 14초 후 등불 앞에서 부활.

### 3-5. 주문

| 주문 | 재사용 | 효과 |
|---|---|---|
| 유성 낙하 (`Q`) | 35초 | 유성 3개 범위 피해 (110 + 12×웨이브) + 화상 |
| 증원군 (`W`) | 20초 | 민병 2명을 16초간 소환, 가장 가까운 길 위로 자동 스냅 |

### 3-6. 룬 (25종)

3웨이브마다 무작위 3장 중 1장 선택. 30골드로 1회 다시 뽑기. 희귀도 가중치: 일반 62 / 희귀 30 / 전설 8(+웨이브×0.5).

- **일반 11종** — 타워별 특화(예리한 화살촉, 정제 화약, 영구 동토, 과충전 코일, 성가, 혹독한 훈련), 경제(연금술, 석공 길드, 고물상, 두둑한 지갑), 생존(등불 기름)
- **희귀 9종** — 매의 눈(사거리), 전장의 광기(공속), 행운의 별(치명타), 복리 이자, 영웅의 맹세, 시간 왜곡, 현상금, 원소/강철 증폭
- **전설 5종** — 처형인의 낫(10% 이하 즉사), 서리불꽃(둔화 대상 피해 +30%), 만물 공명(공명 조건 -1), 황금기, 등불의 심장(생명 +8, 등불 폭발)

### 3-7. 경제

- 처치 골드: 적 기본값 × (1 + 3%×(웨이브-1)) × 난이도 × 룬
- 조기 호출: 남은 카운트다운 초 × 1.4 골드 (현상금 룬 ×2.5)
- 성소 수입: 웨이브 시작 시 지급
- 판매: 투자액의 70% (고물상 룬 95%)

### 3-8. 웨이브 생성

웨이브는 **시드 고정 절차 생성**이다. 같은 스테이지의 N번째 웨이브는 항상 같은 구성이므로 미리보기와 재도전 학습이 가능하다.

```
예산   = (7 + 3n + 0.13n² × 후반계수) × 스테이지 배율   (보스 웨이브는 ×0.5)
체력   = (1 + 0.1(n-1) + 0.015(n-1)²) × 스테이지 배율 × 난이도
무리 수 = min(4, 1 + ⌊n/4⌋)  — 이번 웨이브에 처음 등장하는 적은 반드시 포함
```

- 스테이지마다 적 해금 순서(`unlocks`)와 보스 웨이브(`bosses`)를 지정.
- 경로가 2개인 3스테이지는 무리별/개체별로 경로를 번갈아 배정.
- **무한 모드:** 해당 스테이지 클리어 후 해금. 마지막 웨이브 이후 모든 적이 섞여 나오고 5웨이브마다 보스 순환.

### 3-9. 난이도

| | 보통 | 영웅 |
|---|---|---|
| 생명 | 20 | 12 |
| 적 체력 | ×1.0 | ×1.10 → ×1.35 (웨이브마다 증가) |
| 처치 골드 | ×1.0 | ×0.95 |

영웅 난이도 체력을 *처음부터* 높이면 초반 누수 → 골드 부족 → 붕괴의 악순환이 생겨, 웨이브에 따라 점점 오르도록 설계했다.

## 5. UX / 아트 / 사운드

### 5-1. 화면 구성

```
┌──────────────────────── HUD ─────────────────────────┐
│ ♥ 생명  ● 골드  웨이브 n/N │ [다음 웨이브 12초 +17G] 미리보기 │ 1× 2× 3×  ❚❚ │
├──────────────────────────────────────────────────────┤
│ [공명]                                   [정보 패널] │
│                 전 장 (캔버스)                        │
│ [새 적 소개]          [튜토리얼 코치]                 │
├──────────────────────────────────────────────────────┤
│ [영웅 초상·HP·XP][E]   [타워 1~6]       [Q 유성][W 증원] │
└──────────────────────── DOCK ────────────────────────┘
```

- **반응형 레이아웃 모드** (JS가 화면 여백을 측정해 자동 선택)
  - `side` — 좌우 여백이 넓으면 공명·정보 패널을 지도 밖 여백에 배치 (가로 모바일 포함)
  - `stacked` — 세로 화면에선 지도를 위에 붙이고 패널을 아래에
  - 기본 — 지도 위 오버레이
- **터치:** 건설·주문은 *한 번 탭 = 미리보기, 같은 곳 다시 탭 = 확정* (오조작 방지).
- **판매**는 두 번 눌러야 확정.
- **튜토리얼 코치:** 1스테이지 첫 플레이에서 행동 기반으로 진행 (건설 → 시작 → 영웅 이동 → 주문 → 업그레이드 → 조기 호출).

### 5-2. 아트 디렉션

- **밤 + 빛.** 남색 계열의 어두운 지형 위에, 등불·타워 결정·마법 효과만 가산 합성(additive) 글로우로 빛난다.
- 강조색은 **등불 호박색(#FFC46B)** 하나. 타워 고유색(궁수 금색, 대포 주황, 서리 하늘, 비전 보라, 성소 노랑, 병영 초록)은 기능 구분용.
- 모든 스프라이트는 Canvas 경로로 그린 **절차적 벡터 아트** — 해상도 독립, 에셋 0 KB.
- 스테이지별 테마: 숲(반딧불), 설원(눈발), 폐허(불씨와 화로).
- 서체: 제목 *Song Myung* (붓글씨 느낌의 명조), 본문 *IBM Plex Sans KR*.

### 5-3. 사운드

WebAudio로 실시간 합성. 효과음 38종(발사·폭발·번개·처치·건설·업그레이드·보스 등)에 동시 재생 제한(게이트)을 걸어 다수 타워가 쏴도 귀가 피곤하지 않게 했다. 배경음은 느린 패드 화음 + 펜타토닉 아르페지오이며, 전투 중에는 리듬이 추가된다.

## 6. 밸런싱 방법론

`tools/sim.js` 는 브라우저 없이 Node에서 게임 로직을 그대로 실행하는 **헤드리스 시뮬레이터**다. 봇 두 종으로 모든 스테이지 × 난이도 × 영웅을 반복 플레이한다.

- **balanced 봇:** 경로 커버리지가 높은 칸에 6종 타워를 고루 건설·업그레이드, 주문 사용, 조기 호출.
- **lazy 봇:** 궁수탑만 계속 짓고 업그레이드하지 않음 → **반드시 져야 함** (스팸 전략 차단 검증).

현재 수치 기준 결과 (각 4회):

| | 1. 숲 | 2. 협곡 | 3. 왕도 |
|---|---|---|---|
| 보통 · balanced | 100% 승 | 100% 승 | 약 80% 승 |
| 영웅 · balanced | 100% 승 | 약 15% 승 | 약 10% 승 |
| lazy | 전패 | 전패 | 전패 |

봇은 영웅을 움직이지 않고 룬도 첫 번째만 고르므로, 사람이 하면 체감 난이도는 이보다 낮다. 영웅 난이도는 상위 도전 콘텐츠로 의도했다.

튜닝 과정에서 발견·수정한 문제:
1. 1레벨 궁수 스팸이 무손실 클리어 → 업그레이드 효율이 더 높도록 비용·피해 곡선 재조정
2. 2·3스테이지 2웨이브 박쥐 떼가 초반 붕괴 유발 → 비행 적 해금을 3웨이브로, 신규 적 비중 축소
3. 초반 누수 시 골드 부족 악순환 → 시작 골드 상향, 영웅 난이도 체력 점진 상승
4. 완벽한 런은 후반에 골드가 남음 → 후반 체력 곡선을 이차항 위주로, 3스테이지 후반 예산·보스 체력 상향

## 7. 기술 구조

```
index.html          화면 마크업 (타이틀 / 원정지 선택 / 게임)
css/style.css       UI 스타일, 반응형 규칙
js/util.js          수학·시드 난수·색상 유틸
js/data.js          ★ 모든 밸런스 데이터 (타워·적·영웅·룬·스테이지)
js/entities.js      Path, Enemy, Tower, Soldier, Hero, Projectile
js/game.js          Game — 규칙·경제·웨이브·룬·공명 (DOM 의존 없음)
js/render.js        캔버스 렌더러 + 절차적 스프라이트 + 아이콘
js/audio.js         WebAudio 합성 사운드
js/ui.js            HUD·패널·모달·입력·튜토리얼·저장
js/main.js          고정 시간 간격(1/60초) 게임 루프
tools/sim.js        헤드리스 밸런스 시뮬레이터
tools/build.js      단일 HTML 파일 빌드
```

- **로직/표현 분리:** `game.js`·`entities.js` 는 DOM·캔버스를 전혀 참조하지 않아 시뮬레이터에서 그대로 재사용된다.
- **고정 스텝:** 1/60초 고정 업데이트 × 배속 → 2×, 3×에서도 결과가 동일.
- **빌드 불필요:** 클래식 `<script>` 로 구성해 `index.html` 더블클릭만으로 실행 (file:// 지원).
- **저장:** `localStorage` (별·해금·무한 기록·설정·도감 발견 여부). 접근 불가 환경에서도 기본값으로 동작.
