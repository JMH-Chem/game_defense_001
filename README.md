# 등불 수호자 · Lantern Keeper

어둠이 밀려오는 밤, 마지막 등불을 지키는 판타지 **타워 디펜스** 게임입니다.
킹덤 러시식 경로 방어에 분기 업그레이드, TFT식 시너지, 로그라이크식 룬 선택을 섞었습니다.

- 타워 6종 × 3레벨 + 최종 진화 12종
- 공명(시너지) 6종 + 조화 보너스
- 룬 25종 (3웨이브마다 3장 중 1장)
- 조작 가능한 영웅 3명, 주문 2종
- 스테이지 3곳 (보통 / 영웅 난이도, 별 3개 평가) + 스테이지별 무한 모드
- 그래픽·사운드 전부 코드로 생성 — 이미지·음원 파일 없음
- 데스크톱 · 모바일(터치) 지원, 진행 상황 자동 저장

## 실행

빌드 과정이 없습니다. **`index.html` 을 브라우저로 열면 바로 실행됩니다.**

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 을 엽니다.

CSS·스크립트를 모두 한 파일에 담은 배포용 HTML 이 필요하면:

```bash
node tools/build.js
```

`dist/lantern-keeper.html` 한 개 파일로 어디서든 실행할 수 있습니다.

## 조작법

| 동작 | 마우스 / 키보드 | 터치 |
|---|---|---|
| 타워 건설 | 하단 타워 버튼 또는 `1`~`6` → 빈 땅 클릭 (`Shift`+클릭 연속 건설) | 버튼 → 칸을 탭해 미리보기 → 다시 탭해 확정 |
| 타워 관리 | 타워 클릭 → 업그레이드 `U`, 조준 변경 `T`, 판매(두 번 클릭) | 타워 탭 |
| 병영 집결지 | 병영 선택 → `R` → 길 위 클릭 | 같은 방식 |
| 영웅 이동 | 영웅 또는 초상화(`H`) 클릭 → 지도 클릭 | 같은 방식 |
| 영웅 기술 | `E` | 기술 버튼 |
| 주문 | `Q` 유성 낙하, `W` 증원군 → 지점 클릭 | 버튼 → 탭 → 다시 탭 |
| 다음 웨이브 | `N` / `Enter` (일찍 부를수록 보너스 골드) | 상단 버튼 |
| 배속 / 일시정지 | `F` (1×→2×→3×), `Space` / `Esc` | 상단 버튼 |
| 취소 | 우클릭 / `Esc` | × 버튼 |

## 공략 팁

- **상성:** 철갑 골렘은 물리에 강하고(방어력 55%), 망령·주술사는 마법에 강합니다.
- **비행:** 박쥐와 비룡은 점선 하늘길을 따라 등불로 곧장 날아옵니다. 대포·병영은 공중을 못 칩니다.
- **공명:** 같은 타워 2/4/6개마다 보너스, 6종을 모두 지으면 '조화'로 전체 피해 +12%.
- **성소**는 공격하지 않지만 주변 타워를 강화하고 웨이브마다 골드를 줍니다. 일찍 지을수록 이득.
- **보스 대비:** 공허 프리즘은 같은 대상을 오래 지질수록 최대 5배 피해 — 보스 경로 끝자락에 두세요.

## 밸런스 시뮬레이터

브라우저 없이 봇이 모든 스테이지를 플레이해 승률을 보고합니다. `js/data.js` 수치를 바꾼 뒤 돌려 보세요.

```bash
node tools/sim.js
```

인자 순서는 `[스테이지 0~2|all] [normal|hard|all] [aren|lyra|serin|all] [balanced|lazy|all] [-n 반복횟수] [-v]` 입니다. 예를 들어 3스테이지 보통 난이도를 영웅별로 5번씩 돌리려면:

```bash
node tools/sim.js 2 normal all balanced -n 5
```

설계 의도와 수치 근거는 [docs/DESIGN.md](docs/DESIGN.md) 에 정리되어 있습니다.
